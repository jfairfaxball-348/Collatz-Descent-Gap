## Reconstruction grammar and coverage

For each physical positive profile, start with every length-L rational mechanical word generated by phase interval cuts `(-D*j) mod ell`, `D=a-ell`; retain both cut and immediate interior phases and deduplicate, giving exactly L+1 base words. Deform the p-run with profile q using the inherited difference vector `(0,q_1,...,q_p,0)`, rejecting any nonpositive gap. For a gap tuple `g_1,...,g_L`, solve the exact backward composition congruence modulo `3^L`: with `C_0=0`, `C_j=2^{g_j} C_{j-1}+3^{j-1}`, require `2^{sum g} P=C_L (mod 3^L)`. Enumerate **every** residue lift in the inherited band, retain odd P, and check every backward numerator `(2^{g_j}P_j-1)/3` is integral odd. This reconstructs all admissible q=0 physical rows. There is **no high-carry filter**, so the enumerated population is a superset of live rows at every bootstrap.

Forward escape uses the deterministic odd map `F(x)=(3x+1)/2^{v_2(3x+1)}`. If F^j(P)<2^71 for any j, P cannot be on a cycle with least odd state m>=2^71. The scripts assert complete counts and a finite escape bound; an unresolved trajectory raises an error. Independent reconstruction scripts do not import the RL338 core.
