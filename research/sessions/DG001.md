# DG001 — Baseline parity-prefix descent analysis (2026-10-15)

**Status:** mathematical baseline with elementary paper arguments. Not a novelty claim; not Lean-certified. The bridge E=empty remains OPEN.

## 1. Exact affine prefix identity
Fix n>=1. Let x_j=T^j(n), let epsilon_j be 1 if x_j is odd and 0 otherwise, and s_j=sum_{i<j}epsilon_i. Define q_0=0 and
- if epsilon_j=0, q_{j+1}=q_j;
- if epsilon_j=1, q_{j+1}=3q_j+2^j.
Then
\[
x_j=\frac{3^{s_j}n+q_j}{2^j}.
\]
Induction: the even map halves the previous numerator; the odd map multiplies it by 3 and adds 2^j. In particular q_j>=0, and
\[
T^j(n)\ge n\iff (3^{s_j}-2^j)n+q_j\ge0.
\]
This identity is exact at every finite depth, not a probabilistic statement.

## 2. Parity prefixes classify residue classes
For k>=1 each binary word of length k is realised by precisely one residue class n mod 2^k. Inductive proof: once a prefix of length k is fixed, replacing n by n+2^k leaves the first k parities unchanged; at step k the two k+1 lifts n and n+2^k differ by odd 3^{s_k}, hence give opposite next parities. The initial k=1 step is parity mod 2. Thus the map from residues mod 2^k to length-k parity words is bijective.

## 3. Exact finite-horizon survivor classification
Fix word w length k and its residue class r(w) modulo 2^k, and use its corresponding prefix numbers (s_j,q_j). Define
\[
M(w)=\min_{\substack{1\le j\le k\\3^{s_j}<2^j}}\left\lfloor\frac{q_j}{2^j-3^{s_j}}\right\rfloor,
\]
with M(w)=+infinity if there are no such j. Because 3^{s_j} and 2^j cannot be equal for j>=1, when 3^{s_j}>2^j the inequality in section 1 holds automatically (q_j>=0); otherwise it is equivalent to n<=the displayed bound.

**Consequently** the exact set of n>=2 with prefix w and no descent in steps 1..k is
\[
\{n\ge2:n\equiv r(w)\pmod{2^k},\ n\le M(w)\}.
\]
If M(w)=+infinity, the entire positive tail of this residue class survives k steps. If M(w) is finite, only finitely many members do. This is a *finite-depth* result; it does not imply E empty.

## 4. No uniform fixed stopping-time bound
For any k>=1 and any integer t>=1, let n=2^k t-1. For 0<=j<=k,
\[
T^j(n)=3^j2^{k-j}t-1.
\]
Indeed for j<k these values are odd, so every step uses the odd shortened map. Since 3^j>=2^j, T^j(n)>=n for every j<=k (strictly for j>=1). Infinitely many distinct n therefore survive the first k steps. Thus an argument for universal descent cannot simply find one fixed number of steps valid for every n.

## 5. Failure mode and next theorem
The sets of survivors through k steps form a nested sequence, each infinite; the known limiting exceptional set has density zero, but the intersection may still be empty or nonempty. Finite prefix control without an across-all-k positive-integer compatibility theorem does not solve this distinction.
